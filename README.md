🚀 Synthenexa AI - 
Synthenexa is an iterative LLM system that generates, evaluates, and refines code using feedback loops.
It improves outputs over multiple iterations instead of relying on one-shot generation.

🧠 What it does?  

Generates Python code from natural language prompts, 
Runs test cases to evaluate correctness, 
Refines the code using feedback from failures, 
Repeats the process to improve results. 

⚙️ How it works?

Prompt → Code Generator → Evaluator → Refiner → Improved Code
